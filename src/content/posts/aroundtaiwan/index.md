# 行前考量

原本在規劃想要去的景點與交通方式時，發現只有四個縣市(花蓮、台東、高雄、台南)是我們特別想去的，而又正值冬季，東北季風讓北部容易下大雨，因此決定以半搭車半騎車的方式，不僅能讓花東停留的時間更久，也能避開東北角容易下雨的危險

# 路線規劃

順時針繞行，台北出發—>花蓮(2D)—>台東(2D)—>高雄(1D)—>台南(2D)—>台北

# 總結與體悟

本次環島花費全部總計 13,533NTD，花費較高都是在租車與交通上。
在工作了一年多後，因緣際會安排自己一直未能實現的環島夢，說走就走的行程，雖然沒有全部的城市都去到，但這樣反而讓我們更深入玩到每個縣市，尤其在花蓮玉里，原本安排計畫時沒有想到要在此度過一晚，但因朋友說：玉里麵必吃，我們因此駐足於此地，也認識民宿老闆，跟自己有著相同熱血的心，坐而言不如起而行，也品嘗到玉里麵（感覺很像陽春麵，但做法不同，我吃不出來）及當地厲害的米達炭烤雞排。有時人生就是因為意想不到，才顯得更精彩，因緣探索難以挖掘的樂趣，在世界每個土地上，每個人都用不同的方式，活出自己的人生。
