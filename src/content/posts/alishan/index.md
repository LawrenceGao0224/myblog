# 阿里山眠月線歷史背景

阿里山眠月線為日治時期修築的鐵路，目的為搬運砍伐的巨木而建造，而後發展為觀光，也有小火車提供載客服務。眠月線為其中一個支線，止於石猴站，全長「9.2公里」，沿途共經過「24個橋樑與12個隧道」。

![](./7.jpg)

1999年因為921大地震，鐵路坍方而停駛，而後經過一番修復曾經短暫恢復通車，不料2008年又遭遇八八風災再度損毀，至今未再復駛。由於其平坦且優美的景色，使其成為著名的景點。

# 行前準備

由於眠月線為台灣特有種一葉蘭的保護區，因此須先上[林務局網站](https://pa.forest.gov.tw/?utm_source=%E5%A5%BD%E5%A5%BD%E7%8E%A9%E5%8F%B0%E7%81%A3blog&utm_medium=%E9%98%BF%E9%87%8C%E5%B1%B1%E7%9C%A0%E6%9C%88%E7%B7%9A-%E4%B8%80%E7%AF%87%E6%90%9E%E6%87%82%E7%99%BB%E5%B1%B1%E8%B7%AF%E7%B7%9A%E3%80%81%E5%A6%82%E4%BD%95%E7%94%B3%E8%AB%8B%E3%80%81%E6%B3%A8&utm_campaign=%E9%98%BF%E9%87%8C%E5%B1%B1%E7%9C%A0%E6%9C%88%E7%B7%9A%EF%BD%9C%E5%A4%B1%E8%90%BD%E4%B9%8B%E5%9C%B0%E3%80%8C%E7%9C%A0%E6%9C%88%E7%B7%9A%E3%80%8D%E6%98%8E%E5%B9%B4%E5%8D%B3%E5%B0%87%E5%B0%81%E9%96%89%EF%BC%8C%E6%87%B6%E4%BA%BA%E5%8C%85%E5%85%88%E6%94%B6%E8%97%8F%E3%80%90%E7%99%BB%E5%B1%B1%E8%B7%AF%E7%B7%9A/%E5%A6%82%E4%BD%95%E7%94%B3%E8%AB%8B/%E4%BA%A4%E9%80%9A%E6%96%B9%E5%BC%8F/%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A0%85%E3%80%91&utm_term=&utm_content=)申請入園許可，選擇區域：「台灣一葉蘭自然保留區」。

建議需要帶的物品：
1. 頭燈：因為有許多隧道且非常陰暗，建議要攜帶
2. 登山鞋或雨鞋：路上多處泥濘，真心建議不要像我一樣穿New Balance，回去洗得很痛苦
3. 行動糧：可以買些巧克力、麵包、鹽糖等，隨時補充
4. 水： 網上許多人建議2000c.c，因人而異，我個人是600c.c.搞定
（以上建議為單攻，若要扎營可參考其他）

由於近期意外事故不斷，讓阿里山林業鐵路及文化資產管理處決定，於2022年的1月17日至4月30日封閉施工整修，此次封閉將規劃更換、加寬既有木板，增加止滑效果。
也難怪我們爬起來很順，跟過去相比超級安全

# 總結

本身是登山菜雞，這是以個人角度做的評分，覺得難度中下，全長9.2公里的眠月線，一路起伏僅約100公尺，相當平緩好走，且夏天山上溫度10多度，非常舒服，我們11點左右出發抵達終點大概兩點初，單程行走時間約為3-4小時，回程聽見打雷聲，我們加緊腳步，僅花一半的時間回到「沼平站」。
